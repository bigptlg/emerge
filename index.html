Visão geral

Introdução #

Emerge.js é uma biblioteca de animação de scroll que funciona com um único atributo: adicione data-emerge="fade-up" a um elemento e ele ganha vida quando entra na tela. Por baixo dos panos, um IntersectionObserver detecta a entrada do elemento e o CSS — alimentado por custom properties — faz a animação, que roda inteiramente na thread de composição.

core Declarativo de verdade Um atributo por efeito. Sem JS por elemento, sem classes manuais, sem @keyframes para escrever.
Range Scroll-linked Progresso de 0 a 1 ligado à posição do elemento: animações que avançam e retrocedem com o scroll.
Draw Desenho de SVG Traços que se desenham sozinhos, com ordem, stagger e máscara de preenchimento automáticos.
Horizontal Seções horizontais Scroll vertical traduzido em uma faixa horizontal pinada, com velocidade ajustável.
Media Vídeo & frames Arraste o tempo de um vídeo com o scroll — ou percorra uma sequência de imagens num canvas.
Stack Painéis empilhados Seções pinadas que se substituem com fade, slide, zoom, blur ou flip conforme você rola.
Text Texto dividido Chars, palavras ou linhas com stagger automático — e acessibilidade preservada via aria-label.
Spotlight Spotlight interativo Um foco de luz que segue o cursor: revela camadas, escurece ou desfoca o que está fora dele.
Scene Cenas pinadas A hero prende na tela e o scroll revela um painel em oito presets: unfold, fold, bloom, zoom, slide, wheel, curtain e blur.
Magnetic Elementos magnéticos Botões e cards que são puxados pelo cursor, com tilt 3D opcional.
Parallax Parallax por scroll Velocidade, eixos, rotate/scale/opacity e camadas internas, sobre o motor do Range.
Particles Texto em partículas O texto vira nuvem de partículas em canvas: repel, attract ou swirl ao ponteiro.
Melhorias progressivas por padrão

O estado "escondido" só existe depois que o JavaScript inicia o elemento (classe .emerge-init). Sem JS, com prefers-reduced-motion ativo ou ao imprimir, todo o conteúdo permanece visível.

Duas URLs oficiais, dois modos de uso: o bundle (tudo incluso, já registrado) ou os arquivos individuais (você registra cada plugin — e aí a ordem importa, como veremos abaixo).

Opção A — Bundle (recomendado)

O bundle embute o núcleo e os onze plugins. Eles são registrados automaticamente — o arquivo termina com Emerge.addPlugin([EmergeRange, EmergeDraw, EmergeHorizontal, EmergeMedia, EmergeStack, EmergeText, EmergeSpotlight, EmergeScene, EmergeMagnetic, EmergeParallax, EmergeParticles]) — então você não precisa chamar addPlugin manualmente ao usar o bundle.

html 
<!-- 1. Folha de estilo do Emerge -->
<link rel="stylesheet" href="https://cdn.pedrodeoliveira.me/css/emerge.css">

<!-- 2. Bundle: core + todos os plugins, já registrados -->
<script src="https://cdn.pedrodeoliveira.me/js/emerge.bundle.js"></script>

<script>
  const elementos = Emerge.init(); // pronto ✦
</script>
O bundle também carrega o CSS sozinho

Servido por HTTP, o bundle injeta o <link> de /css/emerge.css da mesma origem automaticamente. Para controlar isso manualmente: data-emerge-css="false" desliga o auto-loader (use o <link> próprio) e data-emerge-css="URL" aponta para outra folha de estilos.

Opção B — Arquivos individuais (plugin por plugin)

Distribuído separadamente, cada plugin é apenas uma fábrica exposta como global (EmergeRange, EmergeDraw, EmergeHorizontal, EmergeMedia, EmergeStack, EmergeText, EmergeSpotlight, EmergeScene, EmergeMagnetic, EmergeParallax, EmergeParticles). Registrar é responsabilidade sua, com Emerge.addPlugin(...) — e aqui vem a regra de ouro:

Atenção · ordem obrigatória Range deve ser SEMPRE o primeiro plugin registrado

O Range é o motor de scroll (progresso 0 → 1) que Draw, Horizontal, Media, Text, Scene e Parallax usam nos modos follow / scrub. Registre-o antes de todos os outros; os demais podem vir em qualquer ordem depois dele.

js 
// ✅ CORRETO — Range primeiro, sempre
Emerge.addPlugin(Range, Draw, Horizontal, Media, Stack, Text, Spotlight, Scene, Magnetic, Parallax, Particles);

// ✅ também vale — em chamadas separadas, mantendo a ordem
Emerge.addPlugin(Range);
Emerge.addPlugin(Draw, Horizontal, Media, Stack, Text, Spotlight, Scene, Magnetic, Parallax, Particles);

// ❌ ERRADO — Range por último quebra os modos follow/scrub
Emerge.addPlugin(Draw, Horizontal, Media, Stack, Text, Spotlight, Scene, Magnetic, Parallax, Particles, Range);

💡 No bundle nada disso é necessário: a ordem correta já vem embutida.

Requisitos

  • Navegadores modernos com IntersectionObserver, CSS custom properties e Pointer Events (Spotlight, Magnetic, Particles). Magnetic exige suporte às propriedades individuais translate/rotate/scale; Particles usa <canvas>.
  • O plugin Scene usa position: sticky e unidades svh — e nenhum ancestral da cena pode ter overflow: hidden/auto enquanto o pin estiver ativo (use overflow: clip).
  • A folha emerge.css é obrigatória — sem ela os efeitos não têm estado inicial nem keyframes.
  • Chame Emerge.init() depois do DOM existir (fim do <body> ou DOMContentLoaded).
  • A folha oficial inclui a regra [data-emerge-counter] (dígitos tabulares), mas o bundle atual não traz um plugin Counter — contadores podem ser feitos com o onProgress do Range.

5 minutos

Início rápido #

  1. Inclua o CSS e o bundle

    As duas URLs oficiais, dentro do <head> (ou o CSS antes do fechamento do <body> — só mantenha a ordem CSS → JS).

  2. Marque os elementos

    Adicione data-emerge com o nome do efeito: fade-up, zoom-in, flip-left… O valor vazio equivale a fade.

  3. Inicialize

    Emerge.init() varre o documento, adiciona a classe .emerge-init (estado oculto) e observa cada elemento.

  4. Role a página

    Quando o elemento cruza a viewport, ele recebe .emerge-animate e a animação acontece. Simples assim.

html — página completa 
<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <link rel="stylesheet" href="https://cdn.pedrodeoliveira.me/css/emerge.css">
  <script defer src="https://cdn.pedrodeoliveira.me/js/emerge.bundle.js"></script>
</head>
<body>
  <h1 data-emerge="fade-up">Olá, Emerge!</h1>
  <p data-emerge="fade-up" data-emerge-delay="200">Entrei 200 ms depois.</p>
  <div data-emerge="zoom-in" data-emerge-duration="800" data-emerge-easing="ease-out-back">
    Zoom com rebote
  </div>

  <script>
    window.addEventListener("DOMContentLoaded", () => Emerge.init({
      offset: 120,       // px antes do elemento entrar na viewport
      duration: 500,     // duração padrão (ms)
      delay: 0,          // atraso padrão (ms)
      easing: "ease-out" // curva padrão
    }));
  </script>
</body>
</html>
Dica: use defer

Com <script defer> o bundle executa antes do DOMContentLoaded — inicializar dentro desse evento garante que o DOM já está pronto e que a primeira "dobra" anima na carga.

Stagger manual rápido

Numa lista, aumente o data-emerge-delay de cada item (0, 100, 200…) — ou use o plugin Text para stagger automático por caractere/palavra/linha.

Desabilitando por dispositivo ou largura

Cada "feature" (core, range, draw, horizontal, media, stack, split, spotlight, scene, magnetic, parallax, particles) aceita desativadores individuais — úteis para poupar bateria em telas pequenas:

html 
<!-- desativa o core em qualquer dispositivo móvel -->
<div data-emerge="fade-up" data-emerge-disable="mobile">…</div>

<!-- desativa o Range em celular OU em telas até 768px -->
<div data-emerge-from="enter" data-emerge-to="exit"
      data-emerge-range-disable-phone
      data-emerge-range-disable-size="max@768px">…</div>

<!-- sufixos disponíveis: -mobile · -desktop · -tablet · -phone · -size -->
<!-- tamanhos: "min@1024px" (≥) · "max@768px" (≤) · combinados por vírgula -->

  --emerge-zoom-in: .6;          /* escala inicial dos zoom-in-* */
  --emerge-zoom-out: 1.2;        /* escala inicial dos zoom-out-* */
  --emerge-blur: 12px;           /* desfoque inicial dos blur-* */
  --emerge-perspective: 2500px;  /* perspectiva dos flip-* */
  --emerge-rotate: 12deg;        /* ângulo dos rotate-left / rotate-right */

  /* ---- extras ---- */
  --emerge-pop-overshoot: 1.15; /* pico do pop */
  --emerge-bounce-height: 30px; /* altura da queda do bounce */
  --emerge-swing-angle: 15deg;  /* amplitude do pêndulo */

Plugin · registre sempre primeiro

Range #

O motor scroll-linked do Emerge: mede o percurso do elemento entre from (0%) e to (100%) e entrega esse progresso — para a animação CSS (scrub), para propriedades animadas ou para callbacks a cada frame. Draw, Horizontal, Media e Text o utilizam nos modos follow; por isso ele deve ser o primeiro plugin registrado na instalação individual.

Atributos

AtributoExemploDescrição
data-emerge-from"enter"Ponto de partida (progresso 0). Padrão: enter.
data-emerge-to"exit"Ponto de chegada (progresso 1). Padrão: exit.
data-emerge-follow"" / "0.2"Scrub contínuo da animação CSS. Número = suavização (0–1, quanto maior mais "atrasado").
data-emerge-in"hero"Usa uma zona (data-emerge-zone="hero") como âncora, herdando seus from/to.
data-emerge-zone"hero"Marca um contêiner como zona compartilhada de progresso.

Sintaxe de from / to

Formato "<ponto no elemento>@<posição na viewport>" — pontos aceitam top · center · bottom, porcentagem ("25%") ou px. Palavras-chave prontas:

Palavra-chaveEquivale aSignifica
entertop@100%O topo do elemento encosta na base da viewport (começa a entrar).
enteredbottom@100%O elemento totalmente visível.
centercenter@50%Centro do elemento no centro da tela.
exitbottom@0%A base do elemento encosta no topo da viewport (terminou de sair).
exitingtop@0%O topo do elemento alcança o topo da tela (começa a sair).

Três modos de uso

html + js 
<!-- 1) Scrub CSS: o efeito core é percorrido pelo scroll (avança e volta) -->
<h2 data-emerge="fade-up"
     data-emerge-from="enter" data-emerge-to="center"
     data-emerge-follow>Título que acompanha o scroll</h2>

<!-- 2) Por eventos: dispara ao cruzar from/to (sem follow) -->
<div data-emerge-from="enter" data-emerge-to="exit" data-emerge-once>…</div>

<!-- 3) Zonas: um contêiner compartilha o progresso entre vários elementos -->
<section data-emerge-zone="cap-1" data-emerge-from="enter" data-emerge-to="exit">
  <img data-emerge-in="cap-1" data-emerge="fade-up" data-emerge-follow src="a.jpg">
  <p data-emerge-in="cap-1" data-emerge="fade-up" data-emerge-follow>…</p>
</section>

API JavaScript

js 
// watch() — controle total, com animate + callbacks
const w = Emerge.Range.watch({
  on: "#secao",            // elemento medido (âncora)
  anchor: "#secao",        // opcional, outro elemento como referência
  from: "enter", to: "exit",
  follow: true,            // true = scrub · número = lag · false = eventos
  cssFollow: false,        // não dirigir a animação CSS do elemento
  debug: false,            // true desenha guias from/to na página
  once: false, mirror: false, id: "minha-secao",
  animate: {               // interpolação imperativa (opcional)
    target: ".parallax-img",
    y: [-60, 60],          // px (padrão)
    spin: [0, 360, "deg"],// unidade explícita
    scale: [.8, 1],       // sem unidade
    opacity: [0, 1],      // propriedade CSS comum
    "--emerge-progress": [0, 1] // custom property unitless
  },
  onProgress({ progress }) { /* 0..1 a cada frame de scroll */ },
  onEdge({ edge, direction }) { /* "from"/"to" cruzados, ±1 */ }
});

// utilidades
Emerge.Range.of(el);       // watches ligados ao elemento
Emerge.Range.measure();   // re-medir tudo (ex.: após layout)
Emerge.Range.stop(w);      Emerge.Range.stopAll();
Emerge.Range.all;          // todos os watches ativos
Emerge.Range.CLOCK;        // 1000 ms — duração do scrub CSS

Props de animate: x · y · z · spin · tiltX · tiltY · scale · scaleX · scaleY viram transform; opacity e nomes iniciados por -- são propriedades/custom properties unitless; qualquer outra propriedade CSS recebe px por padrão. target aceita seletor, Element ou lista — e sem ele o próprio elemento é animado.

Draw #

Faz traços SVG se desenharem sozinhos via stroke-dasharray/stroke-dashoffset, com stagger, ordem e preenchimento automático por máscara. Funciona com path, line, polyline, polygon, circle, ellipse, rect.

Demo · desenho ao entrar em cena

<svg data-emerge="fade" data-emerge-draw data-emerge-draw-step="140"> — cada traço entra em sequência de 140 ms.

Scene #

A seção hero prende na tela (pin) e o scroll conduz um painel que desdobra, encolhe, nasce pelo centro, gira ou desfoca até cobrir a cena — em oito presets escolhidos num único atributo. O pin usa position: sticky + espaçador e o progresso (0–1, suavizado) vem do plugin Range, com um único rAF que dorme quando a cena assenta.

Anatomia da marcação

html 
<section class="hero" data-emerge-scene="unfold" data-emerge-scene-distance="1000">
  <div data-emerge-scene-content>… conteúdo da hero (opcional) …</div>
  <div data-emerge-scene-layer="a" aria-hidden="true"></div>
  <div data-emerge-scene-layer="b" aria-hidden="true"></div>   <!-- luzes: só o unfold -->

  <div data-emerge-scene-panel>            <!-- OBRIGATÓRIO · filho direto da cena -->
    … cor, tipografia e conteúdo ficam no teu CSS …
    <div data-emerge-scene-cover></div>        <!-- opcional (unfold) -->
  </div>
</section>

<!-- o preset é o valor do atributo — troque e pronto: -->
<section data-emerge-scene="bloom">…</section>
ElementoObrigatórioPapel na cena
data-emerge-scenesimRaiz da cena; o valor é o preset (default unfold).
-contentnãoConteúdo da hero — cede o lugar ao painel no início do scroll.
-layer="a" / -layer="b"nãoCamadas de luz do unfold (a b “pisca”: nasce e apaga).
-panelsim · filho diretoO painel animado: opacity, transform, border-radius — e clip-path/filter no curtain/blur.
-covernãoCobertura do painel que some durante o unfold.
Duas regras do pin

O painel [data-emerge-scene-panel] deve ser filho direto da cena (a perspective só afeta filhos diretos) e nenhum ancestral da cena pode ter overflow: hidden/auto — use overflow: clip no body, como nesta página.

PresetO painel…Diferencial

Uma cena fold com data-emerge-scene-scale="0" encolhe a página até desaparecer no centro; a cena bloom seguinte faz a próxima div renascer de lá — saída e entrada emendadas sem corte.

Conteúdo dinâmico? Nada a fazer

Um MutationObserver embutido registra automaticamente novos [data-emerge] inseridos no DOM (SPAs, lists infinitas). Para desligar: disableMutationObserver: true + Emerge.refresh() manual.

Extendendo

Criando um plugin #

Um plugin é um objeto com name, defaults, install(core) e hooks. O retorno de install vira a API pública (Emerge.SeuPlugin).

js 
Emerge.addPlugin({
  name: "Wiggle",
  defaults: { wiggleIntensity: 10 },
  install(core) {
    return { wiggle(el) { /* … */ } }; // vira Emerge.Wiggle
  },
  hooks: {
    init() { /* escaneie o documento aqui */ },
    observe({ el, opts }, core) {
      // chamado para cada [data-emerge] registrado
      if (core.hasAttr(el, "wiggle")) {
        core.claim(el, "Wiggle"); // assume o elemento
      }
    },
    in({ el }) {},  out({ el }) {},   // entrou / saiu da viewport
    unobserve({ el }) {},  refresh() {},  teardown() {}
  }
});

No core você encontra: attr/numAttr/hasAttr (leitura de data-emerge-*), dispatch, claim/release/isClaimed, isDisabledFor, device, prefersReducedMotion, resolveEasing e utils.clamp/lerp. Se o seu plugin usar scroll, consuma o Emerge.Range — e lembre-se: registre o Range antes dele.
