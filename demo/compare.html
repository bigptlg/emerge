Antes e depois, com um divisor.

Duas camadas sobrepostas e um divisor interactivo: arrasta, clica numa posição ou usa o teclado (setas, Home, End, PageUp/PageDown). Autónomo: não usa data-emerge, não depende do Range e funciona com reduced-motion.

modos slider · hold orientação horizontal · vertical camadas imagens ou HTML api set() · hold() · get()

1 Horizontal e playground

O 1.º filho fica à esquerda, o 2.º à direita. Experimenta os controlos: nada precisa de código.

2 Vertical

  
data-emerge-compare-orientation="vertical": o divisor é horizontal; o 1.º filho fica em cima. Teclado: ↑ ↓.

  

    
    
  







  
2b Segurar para ver a outra versão

  
data-emerge-compare-mode="hold": sem divisor. Prime e mantém (rato ou dedo) em qualquer ponto para ver a 1.ª camada; ao largar volta à 2.ª. Pelo teclado: Espaço ou Enter no botão.

8 Personalização por CSS

  
O estilo “acento” da secção 4, inteiro:


.st-acc {
  --emerge-compare-line-color: var(--acc);
  --emerge-compare-line-width: 3px;
  --emerge-compare-handle-size: 54px;
  --emerge-compare-handle-bg: var(--acc);
  --emerge-compare-handle-color: #fff;       /* cor das setas */
  --emerge-compare-handle-border: 0;
  --emerge-compare-focus-color: #fff;        /* anel de foco do teclado */
}
/* sem indicador, só linha */
.st-minimal .emerge-compare-handle { display: none; }
/* estados: hover e arrasto */
.st-square .emerge-compare-divider:hover .emerge-compare-handle { rotate: 8deg; }
.my-cmp.emerge-compare-dragging { cursor: grabbing; }
