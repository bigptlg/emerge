Galeria na horizontal.

Os filhos diretos viram itens de um trilho flex preso; o scroll vertical desloca-o. Mantido por compatibilidade — para código novo usa Reel (mapeamento direto: data-emerge-horizontal → data-emerge-reel).

opções speed · top · pin · reverse · ease tokens --emerge-horizontal-gap · -item-width api goTo() · measure() · of() · all

1 Trilho simples

speed="1.2" alonga o espaçador (viagem mais lenta). Os botões no canto usam goTo().
