Plugin · Range

O scroll é o relógio.

O Range mede o progresso 0→1 de um elemento entre from e to e entrega-o a animações CSS (scrub), a propriedades interpoladas ou a callbacks. Este título está literalmente a ser desenhado pelo teu scroll — sobe e desce.

ativadores from · to · follow · in · zone api watch() · of · measure · stop eventos onProgress · onEdge

1 Scrub CSS (data-emerge-follow)

Cada cartão usa um efeito do Core, mas o scroll conduz o avanço e a reversão. O número em follow é a suavização (quanto maior, mais “atrasado” fica).

fade-up · follow
zoom-in · follow="0.4"
flip-left · follow
reveal-right · follow

Scrub sem pin, direto no fluxo.

<h2 data-emerge="fade-up"
    data-emerge-from="enter" data-emerge-to="center"
    data-emerge-follow="0.2">O scroll é o relógio.</h2>

2 Contador, anel e órbita (watch + onProgress)

Não há plugin Counter: contadores e medidores são um onProgress do Range. A caixa abaixo percorre 160vh; o painel fica preso com CSS sticky puro — o Range não precisa de pin.

0
0%
progress 0.00 
Emerge.Range.watch({
  on: "#track", from: "enter", to: "exit", follow: true,
  animate: { target: "#orb", spin: [0, 360, "deg"], scale: [.6, 1.4], x: [-120, 120] },
  onProgress({ progress }) {
    n.textContent = Math.round(progress * 1000);
    ring.style.strokeDashoffset = 402 * (1 - progress);
  }
});

3 Zonas partilhadas (data-emerge-zone)

Um contentor define a janela from/to; vários filhos partilham o mesmo progresso via data-emerge-in — perfeito para coordenar título, imagem e texto numa só viagem.

Todos terminam juntos quando o centro da zona chega ao centro do ecrã.

<section data-emerge-zone="z1" data-emerge-from="enter" data-emerge-to="center">
  <img data-emerge-in="z1" data-emerge="fade-left"  data-emerge-follow>
  <p   data-emerge-in="z1" data-emerge="fade-up"    data-emerge-follow>…</p>
</section>

4 Métricas que contam com o scroll

Um watch() por secção alimenta três KPIs com formatos diferentes. Padrão real: números de vendas, dashboards e relatórios.

0
eventos processados por segundo
0.0%
disponibilidade medida em produção
0ms
latência média do primeiro render
Emerge.Range.watch({
  on: "#kpis", from: "enter", to: "center",
  onProgress({ progress }) {
    k1.textContent = Math.round(progress * 24800).toLocaleString("pt");
    k2.textContent = (99 + progress * 0.95).toFixed(1) + "%";
    k3.textContent = Math.round(120 - progress * 87) + "ms";
  }
});
